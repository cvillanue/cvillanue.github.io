# Virtual Robotics Research — GitHub Pages starter

A minimal academic-style research showcase

## Preview locally

Open `index.html` directly in your browser. No dependencies, build tools, or backend required.

## Publish at `https://cvillanue.github.io/`

1. Create a **public** GitHub repository named `cvillanue.github.io` under the `cvillanue` account (if you own it).
2. Upload the **contents** of this folder (not the enclosing folder) to the root of that repository.
3. In **Settings → Pages**, select **Deploy from a branch**, then `main` and `/ (root)`, and save.
4. Wait for GitHub Pages to deploy, then visit `https://cvillanue.github.io/`.

If using a different repository name, the site can instead be hosted at `https://USERNAME.github.io/REPOSITORY/`. All internal links are relative and work there too.

## Replace placeholder illustrations

- Add your real images, for example `assets/empath-screenshot.png` and `assets/cubebot-screenshot.png`.
- In `index.html`, replace the corresponding `src="assets/empath-placeholder.svg"` and `src="assets/cubebot-placeholder.svg"` with the new paths. Update `alt` text as appropriate.
- Images are placeholders intentionally, not actual captures of your simulations.

## Project links

- **cubeBot Code** points to `https://github.com/cvillanue/cubeBot`.
- **EMPATH Results** points to the included `results/empath.html` starter page. Review it before publishing and add verified plots and metrics.
- EMPATH Code, both Paper links, and cubeBot Results are omitted because no published destinations have been provided yet. Add them later by copying the relevant `<a>` elements in `index.html`.
