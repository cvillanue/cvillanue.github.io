Project EMPATH

Empathetic Modeling and Predictive Assistance for Teaming with Humans

In Progress

CoppeliaSim · Python · Bayesian Inference

A virtual human–robot collaboration environment in which a Sawyer robot observes a person performing block-selection and assembly tasks. The system estimates whether the person is likely to recover independently or need assistance, then evaluates whether to wait or intervene.

Preliminary Results

cubeBot: ROS 2 Mobile Robot Simulation

ROS 2 · Python · Gazebo · LiDAR

A simulated differential-drive mobile robot integrating velocity commands, laser scans, and odometry. The project provides a foundation for experimenting with perception, robot motion, and autonomous navigation.
